The Saddle Path

Capital is inherited and cannot jump. Consumption is chosen and can. Pick consumption too high and the economy runs out of capital; pick it too low and it accumulates forever and never spends it. Exactly one choice survives — and that knife-edge is the equilibrium.

Impatience. It appears only in the ċ = 0 locus, so it moves the vertical line and leaves the hump alone.
Why exactly one path survives

Above the saddle path, capital is run down and hits zero in finite time with consumption still positive — infeasible. Below it, capital grows without bound and is never consumed, which violates the transversality condition lim e−ρtu′(ct)kt = 0 — not optimal. Feasibility rules out one side, optimality the other, and a single trajectory remains. Contrast Solow, where every starting point converges because there is no jump variable to get wrong.
